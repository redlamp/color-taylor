Lucide candidates - blended vs per-channel RGB sliders

Rendered from the installed lucide-react (v1.7.0) at 14px, the size the plugin's toggle-group items use, on Figma's panel gray. Left chip of each pair is shown pressed.

What Figma itself uses

From figma-plugin-ds, their published plugin design system. Their blend icon is a droplet - outline for empty, half-filled for active - not overlapping circles. Note this is Figma's layer blend mode, a different concept from channel ramps; their color picker has no RGB sliders at all, only numeric fields, so there is no direct precedent to copy.

icon--blend / icon--blend-empty Figma's own pair, drawn at 14px for comparison.

Pairs

Blend / Droplet Overlapping discs vs a single one. The literal additive-mix symbol; the closest thing Lucide has to "these channels combine".
Blend / Contrast Same left side, but a half-filled disc for the isolated ramp - it reads as "one channel, black to full".
Layers / Layers2 Stacked vs single. Reads as depth rather than color, but the pair is unambiguous.
Combine / Split Verbs rather than nouns: merged vs separated. Strong metaphor, less color-specific.
Palette / Droplets Mixed palette vs discrete drops. Warmer, more color-native, slightly less precise.
Merge / Split Flow lines converging vs diverging. Very legible at 14px.
Component / Circle Four nodes vs one. Abstract, but distinct in silhouette.
Rainbow / Signal Continuous spectrum vs stepped bars. Evocative, a bit loose.
