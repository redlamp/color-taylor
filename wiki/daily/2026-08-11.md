## Merge-risk pass, then the design work

Started by auditing what merging `feat/figma-plugin` would actually mean. Findings worth keeping: no test gate on the deploy, 51 commits that had never seen CI, and an undocumented app overhaul riding along (`ColorHexagon` +1100 LOC, a WebGL shader, Web Audio). Merged to `dev` first so CI had something to say about it, then worked off `dev`.

Audited `src/index.css` and found two real bugs, both fixed:

- a `@media (prefers-color-scheme: dark)` block that fired regardless of the user's choice, leaving `--border: #2e303a` on a white page and redefining `--accent` to purple. `ThemeProvider` already reads the system preference in JS, so the block was pure interference. Nine elements were measurably wrong.
- `--muted-foreground` at 4.34:1 on `--muted` — under AA. Now 0.53, which is 4.84:1.

Also removed ~35 dead lines (`--chart-1..5`, `--sidebar-*`, `--text-h`, `--mono`, `--font-size-*`).

## Five specimens, then one

Built five visual treatments to choose from: Hard Set (neo-brutal), Machined, Instrument, Set in Rules, Sympathetic. The user ruled out Hard Set, liked Sympathetic's idea of the surface echoing the selected color, and flagged that two of the specimens used misleading gradients — Channel-mode slider ramps and a fully-saturated brightness bar. Fixed those; the lesson is that a specimen showing the component wrong is worse than no specimen.

Replaced Set in Rules and Instrument with Anodised and Keyline, and the result is [[decision-border-color-effects]] — Anodised as the resting style, Keyline's glow and rim light derived from hue angle and saturation distance, on by default, app only.

## Consistency and layout

- Collapsible headers modernised; Recent/Saved actions became Lucide icons, but Sort stayed text. Briefly made Sort an icon per mode, which was wrong twice over — five glyphs for User/Hue/Sat/Bright/Alpha are guesswork, and the plugin it was meant to match had always kept Sort as a label.
- First pass shrank everything too far. The user's words: "the header sizes are very small, the padding is very small, the buttons and switches are not consistent." Unified every control at 32px, which is what the system already used.
- The two columns are a CSS Grid now rather than a flex row, with `fr` maxima so they shrink proportionally — Δh 0 at every width. The Color Editor absorbs the slack, with a designed default height so the sliders panel stops shifting ~20px to match the hexagon.
- Panel collapse got three fixes: 8px of dead space under collapsed titles (a grid item's padding counts toward its minimum contribution, so `0fr` resolved to 8px), a -6px title drift (`min-h-8` is border-box; `box-content h-8` isn't), and a cropped selection ring (my own `overflow-hidden`, now derived so it only clips while collapsed).

## Audio, borders, CI

- Audio is off by default in the first release — [[decision-audio-off-by-default]].
- Card borders made fainter in both themes, quantified as perceptual lightness difference rather than opacity: both now ΔL 0.050 against their surface, where before light and dark were 1.33× apart. This meant splitting `--border` from `--input`, because the steppers were borrowing the card token and lost their input affordance when it got fainter.
- Test and deploy were two workflows, so a push to `main` started both at once and the deploy published whether or not tests passed. `needs:` only works between jobs in one workflow, so they are now one `ci.yml`. Verified on both paths: `test: success / deploy: skipped` on dev, and on main the test job ended 20:38:13Z with deploy starting 20:38:15Z.

## The plugin regression

The user reported swatches 2–4px wide and the right-hand padding gone at minimum panel width. Two separate causes, both measured rather than guessed:

1. `figma.css` sized the swatch grids via `#saved-colors .grid`, and `CollapsibleSection` now animates height with a two-row grid carrying the bare class `grid`. The rule matched the animator, gave it six columns, and pinned the content region to the first 48px track — swatches came out at 2.9375px. Fix and the general lesson: [[decision-plugin-css-hooks]].
2. The header actions genuinely do not fit 300px. Sort's 104px floor plus 56px each for Clear and Defaults is 224px with gaps, so the header's min-content was 286px inside a 276px section, and a block cannot be narrower than its min-content — the section overflowed 10px right and carried the padding with it.

Re-floored all three against the panel's 11px type: 86px for Sort, 48px for the confirming actions. Both numbers came from cycling every state; my first guesses (76 and 40) both failed, which is exactly why the app's comment says these are measured.

On `fix/plugin-swatch-grid`, two commits, not pushed. Verified at 300/320/400/511/512/560/720px, and lint/typecheck/4-of-4 Playwright all green.
