## Findings

**Swatch persistence was broken, not missing.** The plugin UI is a null-origin iframe where `localStorage` raises `SecurityError`. Every access was already wrapped in try/catch, so reads returned nothing and writes vanished silently — saved swatches had *never* survived closing the panel. Fixed with a storage seam. See [[decision-clientstorage-swatch-seam]].

**Duplicate DOM ids.** `ColorSlider` derived its id from its label, so RGB's B and HSB's B both emitted `slider-b`. Three collisions (`slider-b`, `slider-h`, `slider-s`), and `slider-b` was live in the app permanently, not just the plugin. Fixed by namespacing on a required `group` prop; the same fix gave the sliders distinguishable accessible names ("Blue channel" vs "Brightness channel"). See [[decision-scoped-slider-ids]].

**`loadAllPagesAsync` on every launch.** Found during a guidelines audit. Figma's own typings say to avoid it under `documentAccess: "dynamic-page"` and use `PageNode.on("nodechange")` instead. We only ever read the current page's selection, so it was pure cost. Swapped. See [[research/figma-plugin-review-guidelines]].

**`figma/README.md` had drifted** — it still said stroke painting and multi-edge resize weren't implemented and quoted a 470 KB bundle; both shipped and the bundle is 179 KB. Rewritten, along with the stale `code.js` header and the `.gitignore` comment.
